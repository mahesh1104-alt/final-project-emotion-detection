# Emotion Detection Application

An AI-based web application built with Python, Flask, and the Watson NLP Emotion Predict library to analyze the emotional sentiment of user-submitted text.

## Features
- Detects anger, disgust, fear, joy, and sadness.
- Identifies the dominant emotion.
- Handles empty and invalid inputs gracefully.
- Web deployment using Flask.
- Fully unit-tested and compliant with PEP 8 standards.
